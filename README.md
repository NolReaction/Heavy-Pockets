# Heavy Pockets

Два игрока обыскивают ящик в открытом грузовом порту и выносят добычу к зелёным таможенным воротам на северо-востоке. Двор занимает 144 × 112 м. На западе проходит железная дорога с маневровым тепловозом и вагоном леса, на востоке стоят портовый кран и причал с катером. Локальный рейд можно собрать на Windows x64 и macOS. Рюкзак и содержимое ящика живут до завершения рейда.

В редакторе нажмите **Play**, затем **Esc → Оформление порта**. «Северный порт», «Грузовой плакат» и «Синий час» можно сравнить с одной позиции. Выбор сохраняется на этом компьютере.

Игрок собирает портового рабочего из модульных деталей. В меню **Esc → Гардероб** доступны тон кожи, причёска или каска, лицо, верх, брюки с обувью и расцветка. Перетащите модель мышью, чтобы повернуть, или нажмите **Приблизить**, чтобы рассмотреть лицо. **Применить** сохраняет выбор на этом компьютере. Другие игроки видят собранный образ, когда персонаж появляется в поле зрения. [Источник модели](ThirdPartyNotices/DepotRunner-Modular-Men.txt)

При коротком взгляде в сторону сначала разворачиваются голова и плечи. При дальнейшем повороте камеры следом доворачиваются таз и ноги.

В [сцене Blender](ArtSource/DepotRunner.blend) одежда и варианты головы привязаны к общему скелету. Для новой куртки возьмите существующую деталь верха за образец весов плеч, локтей и таза. Пары брюк и обуви используют одинаковый индекс. Выбранный в сравнении бег Mixamo включён в готовую игру. Свежий клон использует запасной спринт Quaternius, пока разработчик не добавит локальную анимацию. [Источники движений](ThirdPartyNotices/Character-motion.txt)

Чтобы обновить существующую деталь, в Blender откройте Text Editor и запустите встроенный скрипт `Export wardrobe.py`. В Unity выберите **Heavy Pockets → Character → Update wardrobe meshes from FBX…** и укажите файл `HeavyPockets-DepotRunner.fbx` из временной папки. Префаб сохранит ссылки на меши и материалы.

## Запуск локального рейда

В Unity откройте сцену `Assets/HeavyPockets/Depot.unity` и нажмите **▶ Play**. Редактор запустит выделенный сервер на этом компьютере, подключится к рейду и откроет игровой вид. Кнопка **Stop** завершит сессию. Соберите сервер перед первым запуском и после изменений серверной логики.

### macOS

Для локального рейда используйте копию проекта с удалённой строкой `com.playeveryware.eos` в `Packages/manifest.json`. В Unity Hub добавьте модуль **Mac Dedicated Server Build Support** для установленной версии редактора. Лаунчеру нужны Python 3 из Xcode Command Line Tools и системный OpenSSL.

1. В редакторе выберите **Heavy Pockets → Build macOS dedicated server**, затем **▶ Play**. Клиент в этом режиме работает внутри Unity.
2. Для запуска двух отдельных игровых окон также соберите **Heavy Pockets → Build macOS client** и выполните `./Play-Mac.command` из папки проекта. Приложения находятся в `Build/Development-Mac`.

### Windows

Для Play в редакторе выберите **Heavy Pockets → Build Windows dedicated server**.

Предыдущая версия с закрытым терминалом доступна в [архиве для Windows x64](Releases/Heavy-Pockets-Depot-Windows.zip). [Запись проверки движений](Verification/Movement.mp4) · [Примерочная](Verification/A-wardrobe.png). Предыдущая [сборка с Easy Anti-Cheat](Releases/Heavy-Pockets-Movement-EAC.zip) публикуется отдельно.

Для готовой Windows-сборки распакуйте архив целиком и откройте **Play.cmd**. Для запуска из исходников сначала соберите клиент и сервер по инструкции ниже. Скрипт откроет два игровых окна. В PowerShell из папки проекта выполните команду.

~~~powershell
.\Play.cmd
~~~

Щёлкните внутри окна, чтобы управлять персонажем. **WASD** — движение, **мышь** — обзор. **V** переключает вид от первого и третьего лица, **X** меняет плечо камеры в виде от третьего лица. **Esc** открывает меню рейда с гардеробом и рюкзаком. Сетевой рейд продолжается, пока меню открыто. Если порт 17777 занят, запускатор выберет свободный.

## Как устроен обыск

Первый игрок начинает за перегородкой, второй рядом с ящиком. При первом разрешённом обыске сервер укладывает вещи от верхнего левого угла с учётом их размера. В тестовом ящике всегда есть полевой и экспедиционный рюкзаки, подсумки всех четырёх уровней, четыре или пять разных грузов и один предмет снаряжения — карабин, пистолет или бронежилет. Обыск раскрывает вещи по порядку.

При открытии в сетке 6 × 6 сразу видны места и габариты всех вещей. Каждый неопознанный предмет занимает свой прямоугольник. Обыск одной вещи занимает 0,75 секунды. По завершении открываются её иконка, название и редкость. Прогресс текущей вещи обновляется по времени сервера. Если закрыть ящик и открыть снова, обыск продолжится с сохранённого места. Пустые клетки доступны сразу. Другой игрок обнаруживает вещи самостоятельно.

Ящик открывается ближе к центру экрана. Справа остаются сумка и снаряжение персонажа. С открытым рюкзаком можно идти и осматриваться. Если отойти от ящика, его сетка закроется, а личный рюкзак останется открыт.

В начале рейда у игрока есть основное и запасное оружие, бронежилет, полевой рюкзак и подсумок. Перетащите рюкзак в ячейку над сеткой 6 × 9. Без рюкзака открыты первые четыре ряда (24 клетки), с полевым — шесть (36 клеток), с экспедиционным — все девять (54 клетки). Перед уменьшением вместимости освободите нижние ряды. В подсумке четыре отделения, расположенные квадратом 2 × 2. Уровень от I до IV определяет, сколько отделений доступно. Менять подсумок можно на базе перед следующим рейдом.

[Экипировка и открытый ящик](Verification/A-gear-crate.png) · [Карточка предмета](Verification/A-equipment-card.png) · [Быстрый доступ в рейде](Verification/A-gear-quick.png)

Снаряжению назначены три категории редкости. У редкого снаряжения голубой акцент, у эпического — фиолетовый, у легендарного — янтарный. Среди грузов встречаются также обычные предметы с серым акцентом. После опознания редкость видна в карточке предмета.

Зажмите ЛКМ на любой части вещи. Изображение следует за мышью, а рамка показывает место укладки. **R** поворачивает предмет вокруг собственного центра. После отпускания вещь остаётся в выбранном месте, пока сервер подтверждает перенос и обновляет обе сетки. Если место занял другой игрок, интерфейс показывает подтверждённую сервером раскладку. Сервер проверяет границы, пересечения, владельца и доступ к ящику.

## Режимы защиты

**Локальный плейтест** использует транспорт DTLS и до двух одноразовых приглашений со сроком входа пять минут. Сервер привязан к loopback. Он рассчитывает положение персонажей, ограничивает частоту команд и отправляет координаты соперника, когда между персонажами есть прямая видимость. Локальные лаунчеры работают без сервисов Epic.

На каждом шаге симуляции сервер вычисляет положение камеры по позиции игрока, режиму обзора, углам и формату игрового окна. Камера через плечо укорачивает дистанцию у препятствий. Сервер проверяет точки на силуэте модели с учётом её поворота, поля зрения и геометрии укрытий. Когда одна из точек выходит из-за стены, соперник появляется с правильным поворотом. На тонких выступах граница может расходиться с изображением на несколько пикселей. При полной потере видимости сервер отправляет команду скрытия без координат и прекращает обновления соперника. Последняя уже показанная позиция и фиксированные точки старта тестовой карты могут быть известны игроку.

**Сборка Easy Anti-Cheat** использует EOS Connect и интерфейсы Anti-Cheat Client/Server. Игровое состояние отправляется после проверки личности и события RemoteAuthComplete от Epic. Режим выбирается во время сборки, у него отдельная версия сетевого протокола. Для защищённого плейтеста требуется настройка продукта и активация модулей в Epic Developer Portal. [Подключение продукта и запуск](Tools/EasyAntiCheat.md).

## Сборка и проверка

Для получения исходников и архива EOS нужен Git LFS. Перед клонированием выполните **git lfs install**, затем **git clone https://github.com/NolReaction/Heavy-Pockets.git**. В уже клонированном проекте выполните **git lfs pull**. Архив **com.playeveryware.eos-6.3.0.tgz** находится рядом с папкой **Assets** и подключён относительным путём в **Packages/manifest.json**. После импорта проект показывает меню **EOS Plugin**. Настройка EAC и команды сборки описаны в [руководстве](Tools/EasyAntiCheat.md).

Версии проекта — Unity 6000.3.26f1 LTS, Netcode for GameObjects 2.13.3 и Unity Transport 2.7.4. Для Windows-сборок нужны модули Windows и Windows Dedicated Server. Добавьте папку проекта в Unity Hub. Сцена находится в Assets/HeavyPockets/Depot.unity. Тестовые программы запускайте из папки проекта.

~~~powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Tools\Build-Raid.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File .\Tools\Test-Raid.ps1 -ShowClients -CaptureMotion -Port 18156
powershell -NoProfile -ExecutionPolicy Bypass -File .\Tools\Test-RaidInvitations.ps1
~~~

Сетевой тест запускает три отдельных процесса. Он сверяет журнал отправки сервера с журналами приёма обоих клиентов, проверяет создание одного ящика, постепенное раскрытие, продолжение обыска, гонку за одним предметом, его возврат, поворот прямоугольной вещи, раскладку у края сетки, отказ при пересечении двух вещей, эвакуацию, камеры и сокрытие позиций за стеной. Путь к свежему прогону выводится в консоли. Без графики используйте -HeadlessClients вместо -ShowClients.
